# Tracker - Developer Productivity & Growth Dashboard

A modern, responsive developer productivity and growth tracker web application built with React, Vite, Tailwind CSS, Chart.js, and Lucide React.

## Features

1. **Coding Time Tracker**: Live timer (Play/Pause/Reset) tracking daily active coding time.
2. **Weekly Time Analytics**: Chart.js bar chart displaying weekly coding hours (Mon-Sun).
3. **Task Planner**: Add, check off, and delete daily dev tasks with real-time progress tracking.
4. **Task Completion Doughnut Chart**: Visual doughnut chart showing completed vs pending tasks.
5. **GitHub Integration**: Input GitHub username to view recent repository activity.
6. **Skill Progress Tracker**: Update proficiency levels (0-100%) for dev skills and compute average skill level.
7. **Smart Insights & Recommendations**: AI productivity coach analyzing daily metrics and providing actionable tips.
8. **Dark/Light Mode**: Seamless theme toggling saved in `localStorage`.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/sanjeet-saini/tracker.git
   cd tracker
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
